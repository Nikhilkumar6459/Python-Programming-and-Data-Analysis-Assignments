# Python Assignments: Fundamentals, Advanced Programming & Data Analysis

## Project Description

This repository contains a collection of Python programming assignments covering fundamental programming concepts, intermediate problem-solving, advanced Python techniques, data preprocessing, statistical analysis, and data visualization.

The project is organized into three Python scripts, progressing from basic programming exercises to file handling, regular expressions, object-oriented programming, and data analysis using popular Python libraries.

It demonstrates practical Python applications for solving programming problems, manipulating data structures, cleaning datasets, performing statistical calculations, encoding categorical variables, standardizing numerical features, and visualizing data.

## Project Objectives

- Strengthen Python fundamentals through practical programming exercises.
- Develop reusable functions for mathematical calculations and string manipulation.
- Work with lists, tuples, sets, and dictionaries.
- Perform file operations and text processing.
- Apply regular expressions for pattern matching and data validation.
- Understand exception handling and object-oriented programming.
- Explore datasets using statistical summaries.
- Handle missing values and duplicate records.
- Apply categorical encoding and numerical standardization.
- Create visualizations to identify patterns and relationships in data.

## Installation and Requirements

Install Python 3 and the required libraries for the data analysis script:

```bash
pip install numpy pandas matplotlib scikit-learn
```

The first two scripts primarily use Python's standard library. The third script requires the data analysis libraries listed above.

## How to Run

Run each script from the terminal:

```bash
python 01_basics_intermediate.py
python 02_advanced_python.py
python 03_data_preprocessing_statistics.py
```

**Note:** Some functions require external CSV datasets, such as `iris.csv`, `Data.csv`, or `winequality-red.csv`. Place the relevant dataset in the working directory or provide the appropriate file path before calling those functions. Not every function is executed automatically when a script runs.
